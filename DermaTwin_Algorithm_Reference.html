DermaTwin — Algorithm Reference

THEIA-Core v5.0 · Spatial-Tensor Edition · 2026-09-07

v4.2 DEPRECATED: BCT, TCM, LTI, RSS, RVI, GLCM — FFT artifacts, 2D cut-plane false negatives, arbitrary displacement sensitivity. All replaced by spatial structure tensor pipeline.

1. Preprocessing

Dermascan RGB → Inverse LUT → gray (0–255). Rotate 90° CW. Surface align (gray≥15, σ=3.0). Crop 3mm. pxPerMm = height / 20.0

2. Layer Segmentation

Epidermis: Mean A-line peak → DEJ valley. Cap 0.30mm.

Papillary: $T_{pap} = \min(1.5 T_{epi}, 0.18\text{mm})$. Hypo: 30% plateau drop, clamp DEJ+2.8mm. RetMid: 50% split.

3. Shadow Detection

$$\text{validColumn}[c] = \left(\frac{|\{z:\text{gray}<10\}|}{z_{hypo}-z_{DEJ}} < 0.60\right)$$

4. Pixel Classification (10 MHz)

$\text{LEP}_{max} = \text{round}(30 \times (50/f)^{0.35}) = 53$

5. Tetra-Core Pipeline

① PVR — 표재 결손율 (Tier 1 only)

$$\boxed{PVR = \frac{N_{LEP}}{N_{MEP} + N_{HEP}}}$$

Trigger: $PVR \geq 0.50$ → Rejuran PN @ 0.3mm

② SCD — 유효 콜라겐 밀도 (All tiers)

$$\boxed{SCD = \frac{N_{HEP} + 0.4 \times N_{MEP}}{N_{total}} \times 100\%}$$

HEP: 100% weight (Type I). MEP: 40% weight (Type III). LEP: 0% weight.

③ PAI — 탄력망 결속도 (Spatial Structure Tensor)

  1. Central differences: $I_x = (I_{c+1} - I_{c-1})/2$, $I_z = (I_{z+1} - I_{z-1})/2$
  2. Structure tensor: $J_{xx} = \overline{I_x^2}$, $J_{zz} = \overline{I_z^2}$, $J_{xz} = \overline{I_x I_z}$
  3. Eigenvalues: $\lambda_{1,2} = \frac{J_{xx}+J_{zz}}{2} \pm \sqrt{\max(0, \frac{(J_{xx}+J_{zz})^2}{4} - J_{xx}J_{zz}+J_{xz}^2)}$
  4. $$\boxed{PAI = \left(\frac{\lambda_1 - \lambda_2}{\lambda_1 + \lambda_2 + \varepsilon}\right)^2 \in [0,1]}$$
Operates on native curvilinear per-column ROI. No FFT, no rectangular crop. Angle-agnostic fiber parallelism measure.

④ CAI — 중력 방어 장력선 (Spatial Vector Energy)

$$\boxed{CAI = \frac{J_{zz} - J_{xx}}{J_{zz} + J_{xx} + \varepsilon} \in [-1, +1]}$$

Horizontal fibers → large $I_z$ → $J_{zz} \gg J_{xx}$ → $CAI \to +1$.

FWL — 속수분 누수 (Derived)

$$\boxed{FWL = \text{clamp}(40 + 18 \times (1-PAI) \times (1-SCD/100), \; 40, \; 58)\%}$$

Water leaks where both scaffold density and tensor coherence collapse.

6. Health Score

$$HS = 0.35 S_{pap} + 0.40 S_{supRet} + 0.25 S_{deepRet}$$ $$S_t = (0.35\hat{S} + 0.30 \cdot PAI + 0.15\hat{C} + 0.20(1-\hat{F})) \times 100$$

$\hat{S}=\min(1,SCD/80)$, $\hat{C}=\max(0,(CAI+0.3)/0.8)$, $\hat{F}=\max(0,(FWL-40)/18)$
